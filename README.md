# Muse Studio

**Muse Studio** is a powerful and intuitive e-commerce platform designed for showcasing and selling unique ceramic products. Built with Node.js, MongoDB, and EJS, Muse Studio offers a seamless user experience for both customers and administrators.

## Features

- **User-Friendly Interface**: Easily navigate through the website with a clean and modern design.
- **Product Management**: Admins can add, edit, and manage products with features for image uploads and cropping.
- **Search Functionality**: Users can quickly find products using a robust search option.
- **Shopping Cart**: Customers can add products to a cart and manage their selections before checkout.
- **Order Management**: Admins can view and process customer orders efficiently.
- **Offer Management**: Create and manage product offers and discounts.
- **Responsive Design**: Optimized for both desktop and mobile devices.
- **Payment Integration**: Support for online payments through Razorpay.

## Technologies Used

- **Node.js**: JavaScript runtime for building server-side applications.
- **Express.js**: Web framework for building web applications.
- **MongoDB**: NoSQL database for data storage.
- **EJS**: Template engine for rendering HTML views.
- **Bootstrap**: Frontend framework for responsive design.
- **PDFKit/jsPDF**: Libraries for generating PDF reports.
